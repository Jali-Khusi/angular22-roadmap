Install Node.js and npm

Angular's tooling runs on Node.js. npm is included with the Node.js installer.

  1. Download the current LTS release

    Open the official Node.js download page and choose the LTS installer for Windows, macOS, or Linux. LTS is the stable choice for development.

  2. Run the installer

    Use the default installation options and ensure the option to add Node.js to your system PATH remains enabled. On macOS or Linux, follow the installer or package-manager instructions shown on the official page.

  3. Open a new terminal and verify the installation

    Close and reopen your terminal so it loads the updated PATH, then check both versions:

    node --version
npm --version
Expected result Both commands print a version number. If either command is not recognized, reopen the terminal or rerun the installer with PATH enabled.

02

Install Angular CLI

The CLI scaffolds projects and provides commands for development and builds.

  1. Install the CLI globally

    Run this in a terminal. The -g option makes the ng command available from any folder.

    npm install --global @angular/cli

  2. Confirm the CLI is available

    ng version

    The output lists the Angular CLI, Node.js, and npm versions. If your terminal cannot find ng, reopen it and check that npm's global executable folder is on your PATH.

  3. Update the CLI when needed

    Use npm to install the latest CLI version when you choose to upgrade:

    npm install --global @angular/cli@latest
Permission errors? On Windows, use a regular terminal with your normal user account first. Avoid mixing elevated and non-elevated npm installs; use the official npm guidance if your system requires a different global package setup.

03

Create and run an Angular project

Use the CLI to generate a project, install its dependencies, and start the local dev server.

  1. Generate a new project

    Move to the folder where you keep your code, then run:

    ng new my-angular-app

    Answer the prompts. Choose routing if you want page navigation, and select CSS or SCSS for your stylesheet format.

  2. Enter the project folder

    cd my-angular-app

    The CLI installs the project dependencies when it creates the app. If installation was skipped or failed, run npm install here.

  3. Start the development server

    ng serve --open

    This compiles the app and opens it in your browser, usually at http://localhost:4200/. Keep the terminal running while you work; edits trigger a rebuild.

Your first app is running To stop the server, focus its terminal and press Ctrl+C. Start it again later from the project folder with ng serve.

The project is ready for development. The next lesson is Components.
