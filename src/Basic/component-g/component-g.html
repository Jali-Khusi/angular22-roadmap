Create a standalone component

A component is a reusable UI unit with a selector, template, styles, and a TypeScript class.

  1. Generate the component with Angular CLI

    Run this from your Angular project directory:

    ng generate component user-card

    The short form is ng g c user-card. The CLI creates the component class, HTML template, stylesheet, and test file.

  2. Review the component metadata

    Recent Angular projects use standalone components by default. A minimal component looks like this:

    import {{ '{' }} Component {{ '}' }} from '@angular/core';

@Component({{ '{' }}
	selector: 'app-user-card',
	standalone: true,
	template: '<h2>User card</h2>',
	styles: 'h2 {{ '{' }} color: #3178c6; {{ '}' }}',
{{ '}' }})
export class UserCard {{ '{' }}{{ '}' }}

  3. Put view markup in the template file

    For a component generated by the CLI, edit user-card.html for its markup and user-card.scss or user-card.css for its local styles.

Keep components focused A component should own a clear piece of the interface. Split a large view into smaller components when parts can be reused or maintained independently.

02

Render a component

Import a standalone child into its parent, then use its selector in the parent's template.

  1. Import the child component

    In the parent component file, add the child class to the imports array:

    import {{ '{' }} Component {{ '}' }} from '@angular/core';
import {{ '{' }} UserCard {{ '}' }} from './user-card/user-card';

@Component({{ '{' }}
	selector: 'app-dashboard',
	standalone: true,
	imports: [UserCard],
	templateUrl: './dashboard.html',
{{ '}' }})
export class Dashboard {{ '{' }}{{ '}' }}

  2. Use the selector in the parent template

    <h1>Dashboard</h1>
<app-user-card></app-user-card>

    The selector must match the child's selector value exactly. Angular renders the child wherever that element appears.

  3. Pass data with an input

    Declare a typed input in the child and bind to it from the parent:

    import {{ '{' }} Component, input {{ '}' }} from '@angular/core';

export class UserCard {{ '{' }}
	name = input.required<string>();
{{ '}' }}

<app-user-card [name]="'Taylor'"></app-user-card>
Standalone imports Every standalone component used in a template must be listed in that component's imports. If Angular reports an unknown element, check the selector spelling and the parent's imports.

03

TypeScript in a component

The component class holds typed data and behavior that the template can display.

  1. Declare properties with types

    export class ProfileCard {{ '{' }}
	name: string = 'Taylor';
	visits: number = 3;
	isMember: boolean = true;
{{ '}' }}

    Types help TypeScript catch invalid values while you develop. TypeScript can infer simple types, so name = 'Taylor' is also typed as a string.

  2. Display class data in the template

    Interpolation displays a value as text. In your HTML template, use {{ '{{' }} name {{ '}}' }} to show the name property.

    <h2>{{ '{{' }} name {{ '}}' }}</h2>
<p>Visits: {{ '{{' }} visits {{ '}}' }}</p>

  3. Add a method for behavior

    export class ProfileCard {{ '{' }}
	visits = 3;

	addVisit(): void {{ '{' }}
		this.visits += 1;
	{{ '}' }}
{{ '}' }}

    The void return type means the method does not return a value. Use this to access properties on the current class instance.

Class and template work together Keep the template focused on displaying the view. Put calculations and event behavior in the component class, and use types to make the data contract clear.
